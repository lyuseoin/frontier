# 공개 배포
Streamlit Community Cloud: 저장소 lyuseoin/frontier, 브랜치 secure-dashboard-v2, 실행 파일 app.py, Python 3.12. 기본 기능은 Secrets 설정 없이 실행됩니다. 원본 main 브랜치는 변경하지 않습니다.

# 프론티어 보안 강화 버전

기존 필터버블 대시보드의 분석·추천 모듈과 데이터셋을 재사용한 별도 버전입니다. 기존 소스, 문서, .env는 수정하거나 복사하지 않았습니다.

## 실행
현재 컴퓨터에서는 run.cmd를 실행하거나 http://127.0.0.1:8517 로 접속하세요.
다른 컴퓨터에서는 Python 3.12 이상을 설치한 후 다음을 실행합니다.

    py -m venv .venv
    .venv\Scripts\python.exe -m pip install -r requirements.txt
    .venv\Scripts\python.exe -m streamlit run app.py

기본 모드는 API 키 없이 실행됩니다. 예시로 시작하기 → 개인정보 가리고 확인하기 → 확인한 제목 분석하기 순서로 체험하세요.

## Gemini 설정
.streamlit/secrets.toml.example을 .streamlit/secrets.toml로 복사하고 본인의 GEMINI_API_KEY와 실제 계정에서 사용 가능한 GEMINI_MODEL을 설정하세요. 환경변수도 지원합니다. 모델명은 임의로 고정하지 않았습니다. 비밀 파일은 Git에 올리지 마세요. 기존 앱의 키는 가져오지 않았습니다. 실패 응답을 UI나 로그에 그대로 출력하지 않습니다. 실제 Gemini 연결은 키 미설정으로 실행하지 않았고, 요청 구조·응답 검사·오류 처리는 모의 API로 검증했습니다.

## 달라진 점
- 기본값은 외부 API 미사용. 설명·추천 단계에도 AI 호출 없음.
- 이메일, 휴대전화, 주민번호 형태, URL, @계정, 일부 키 패턴 가림. 일반 이름·주소·얼굴 및 문맥상 민감정보는 자동 탐지하지 못하므로 사람이 확인해야 함.
- 수정 가능한 제목 미리보기. 내용·모드·모델 변경 시 동의 초기화. 현재 내용의 해시와 동의를 서버 전송 경계에서 재확인.
- 이미지 원본을 외부 AI로 보내지 않음. 5MB/1,200만 화소, 실제 PNG/JPEG 검사. 이미지는 참고용 표시이며 자동 OCR은 제공하지 않음. 표시 이미지 재인코딩으로 메타데이터 제거.
- 제목만 한 차례 전송. 분류 지침과 자료 분리, 도구·외부 URL 접근·코드 실행 기능을 모델에 제공하지 않음.
- 지시문 형태 사전 검사와 JSON 필드·항목 수·고유 번호·주제 목록·유한 수치 범위의 엄격한 응답 검사. 완전한 프롬프트 인젝션 방어 또는 의미적 분류 정확성 보장 아님.
- 20초 타임아웃, 재시도 없음, 15초 간격·세션별 시간당 10회. 삭제 버튼은 요청 횟수 제한을 초기화하지 않음.
- 입력·결과·업로드 세션 지우기. 앱 코드에서 원문을 파일/DB/공유 캐시/로그로 저장하지 않음. 호스팅·제공자 기록, 물리적 메모리 삭제까지 보장하지 않음.
- 주제 편중 점수는 정규화 엔트로피 기반 0~100. 기존 주제+관점 혼합 점수와 직접 비교 불가. 추정 관점은 분류 표에서만 표시. 실제 이용자의 확증편향을 진단하지 않음.
- 보안 실험실에서 가상 개인정보 가림과 지시문·잘못된 응답 거부 시연. 실제 AI 공격률이나 분류 정확도를 측정한 실험이 아님.

## 공개 운영 전
현재 127.0.0.1에만 바인딩합니다. 공개 배포 시 별도로 서버 주소/HTTPS/인증, 사용자별·전체 요청 한도 및 API 공급자 지출 제한을 설정해야 합니다. 세션 한도는 새 세션으로 우회할 수 있어 서비스 전체 비용 방어가 아닙니다. 공급자의 유료/무료 사용 조건, 데이터 보관·활용 정책과 호스팅 로그를 확인하고 처리 안내를 맞추세요. 웹 배포에서 API 미사용은 서버 처리이며 브라우저 내부 처리가 아닙니다.
